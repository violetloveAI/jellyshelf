# 备份与迁移

JellyShelf 的商品与上传照片保存在当前浏览器。没有账号和云同步；更换设备时需要自己导出、传送并导入备份。

## 导出

1. 打开「数据与备份」，选择导出完整 JSON 备份。
2. 将下载文件存到自己的「文件」或其他备份位置。
3. 确认文件已保存后，再关闭页面或更换设备。不要把备份提交到公开代码仓库。

备份包括商品字段、尺寸与品相分支、已保存的成交记录和本机上传照片。官网图片只保存链接，不会下载到备份。行情时间范围等界面偏好与照片特征缓存不属于商品备份。

## 导入

1. 在目标设备打开 JellyShelf 的「数据与备份」，选择导出的 JSON 文件。
2. 核对文件名、日期和商品／照片数量。
3. 确认合并导入。完成后，检查商品数量与照片是否正确。

导入按内部记录 ID 合并。没有相同 ID 的商品会新增；已有商品会跳过，保留本机版本。两台设备分别新建的同名商品可能产生不同 ID，因此不会仅凭同名或货号自动去重。重复导入同一个备份不会覆盖本机已有商品。

如果新增商品引用的照片编号与本机照片冲突，或导入过程中空间不足，整次导入会取消。遇到错误请保留原备份，按页面提示处理；不要先清除本机资料。

## 照片与容量

上传支持 JPG、PNG、WebP，单张上限 8 MB。完整 JSON 备份上限 256 MB；内嵌图片会使 JSON 文件大于原图片总大小。浏览器可用空间和可处理文件大小还取决于设备。

如果 iPhone 照片无法上传，请改用受支持的图片格式。照片匹配返回的是外观相似候选，货号、尺寸和品相仍需自己确认。

清除网站数据可能删除商品库；浏览器也可能在储存空间不足等情况下清理数据。长期保存应以自己导出的备份为准。[浏览器储存说明](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)

当前每张上传照片上限为 8 MB，完整 JSON 备份上限为 256 MB。建议使用压缩过的商品照片。备份只包含已保存商品所引用的照片；取消录入或移除的照片不会进入备份，但暂不自动清理其本机存储，以免影响其他页面的草稿。
