中文English

请先保存，再退出；请先备份，再清除数据或卸载。

Save before leaving. Back up before clearing data or uninstalling.

使用与支持简体中文

01 · 先分清演示与自己的资料库

演示图册用来体验浏览、筛选和照片候选，不代表你已经录入商品，也不会作为真实成交依据。自己的资料库从手工保存的记录开始。

网页与 iPhone 应用的入口略有不同：网页可选“录入商品”；iPhone 可点右上角加号，或空资料库中的“录入第一款商品”。iPhone 的备份入口在“我的 → 数据与备份”。

02 · 录入品相与目标价

在网页选择“录入商品”，或在 iPhone 点右上角加号新增商品，填写中文或英文品名，再按实物补充照片、SKU 和尺寸。不同尺寸或品相可分成不同分支。未知官方资料留空，确认后再保存。

全新不含吊牌
EUC
极品二手

良好二手

明显污渍

品相由你按实物判断。录入拿货价和目标成交价下限、上限，金额使用 USD；上限不能低于下限。目标价是你的计划，不是官网定价。

看到保存成功后再退出编辑。网页库存照片支持 JPG、PNG、WebP，单张不超过 8 MB，每款最多 12 张。

03 · 查询与照片相似候选

名称和 SKU 搜索查找已录入资料。官网参考查询目前只匹配随网页附带的少量样例，不会自动抓取整个官网或 eBay。

先给商品保存照片，再使用“拍照查货”。它只比较当前资料库；演示模式只比较演示图册。尽量让实物完整、清晰入镜，减少杂乱背景。

相似度只是排序依据，不是正确率，更不是鉴定结论。相似款、大小款、品相与真伪都需要人工确认。首次网页使用要加载模型；官网图片加载失败时，该图片会被跳过。

04 · 成本与价格证据

当前成本模型用于估算：

预计成本 = 拿货价 + $4 运费 + 目标成交价 × 16%

其中 $4 和 16% 是此工具的固定计算假设，不代表 eBay 或 Whatnot 的实时费率。实际成本应按真实成交和账单核对。

“添加已核验成交”只录入你已确认的同 SKU、同尺寸、同品相、美国美元单件成交。记录实际成交价、日期和来源链接；不含运费、税费，排除套装、取消及退款。接受议价后的实际价格无法确认时，不要用挂牌价代替。

中位数来自你保存且符合筛选的样本，不是全市场价格。没有合格样本会留空，少于 5 笔会提示参考不足。首发日期、MSRP 与品牌官方状态应回到品牌来源核实；缺货不等于停产。

05 · 备份与迁移

iPhone 请先打开底部“我的”，选择“数据与备份”；网页请打开“数据与备份”入口。

  1. 在“数据与备份”选择“导出完整备份（含照片）”，将 JSON 文件保存到你自己的“文件”或备份位置，并确认文件确实存在。
  2. 在目标设备打开资料库，进入“数据与备份”，选择该 JSON 文件。
  3. 核对预览中的商品和照片数量，再确认合并；完成后抽查商品与照片。

备份包含已保存商品引用的本机照片；官网图片仅保留链接。未保存草稿、界面偏好和识别缓存不在商品备份中。

导入按内部记录 ID 合并：已有同编号商品保留，新记录才加入，不会用旧备份覆盖已有内容。同名但不同 ID 的记录可能并存。当前 JSON 备份上限 256 MB；失败时保留原文件和本机数据，不要先清空资料。

无账号和云同步，换浏览器、设备或卸载前请先完成导出。是否能在不同版本间恢复，以该版本实际支持的备份格式为准。

06 · 关闭后不见了，怎么办

正常关闭再打开，不应主动删除已成功保存的资料，但未保存的编辑或中途关闭的写入可能丢失。请使用普通浏览模式，并确认回到相同网站和浏览器。

清除网站数据、浏览器回收储存空间、卸载应用或更换设备，都可能使本机资料不可用。先查找自己保存的 JSON 备份；若页面出现错误，先保留资料和原备份再重试。我们没有云端副本可代为恢复。

系统备份能否恢复取决于你的 iOS 设置及备份状态，不应以此代替已确认保存的手动备份。

07 · 联系支持

请附上应用或网页版本、设备与系统、浏览器名称、操作步骤和错误文字。截图请先遮住私人资料。

通过 GitHub Issues 提交问题

Issues 通常公开，可能需要 GitHub 账号。不要上传完整备份、私人照片或账号凭据；这里不提供私人邮箱或电话支持。

SupportENGLISH

01 · Demo versus your own catalog

The demo catalog lets you try browsing, filters and photo candidates. It is not your saved inventory and is not evidence of real sales. Your own catalog begins with records you manually save.

Navigation differs between the website and iPhone app. On the website, choose “Add product” (录入商品). On iPhone, use the top-right plus button or the first-item action in an empty catalog. iPhone backups are under “My → Data & backup” (我的 → 数据与备份).

02 · Add condition and target prices

On the website, choose “Add product” (录入商品); on iPhone, tap the top-right plus button. Enter a Chinese or English name, and add photos, SKU and size from the actual item. Different sizes or conditions can use separate variants. Leave unverified official details blank.

Assess condition yourself. Enter your purchase cost and target sale-price range in USD; the upper limit must not be below the lower limit. Target prices are your plans, not official retail prices.

Wait for a successful save before leaving the editor. Website catalog photos support JPG, PNG and WebP, up to 8 MB each and 12 photos per product.

03 · Search and photo candidates

Name and SKU searches find saved records. Official-reference lookup currently matches only a small set of bundled examples; it does not crawl the entire official store or eBay.

Save photos for your products before using photo search (拍照查货). It compares only the current catalog, or only the demo catalog in demo mode. Use a clear photo showing the whole item with little background clutter.

Similarity is a ranking score, not an accuracy percentage or an authentication result. You must confirm the item, size, condition and authenticity. The website loads the model on first use; reference images that fail to load are skipped.

04 · Costs and sale evidence

The current estimate uses this model:

Estimated cost = purchase cost + $4 shipping + target sale price × 16%

The $4 and 16% are fixed assumptions in this tool, not current eBay or Whatnot fee schedules. Check actual costs against the completed sale and your statements.

Add a verified sale only after confirming the same SKU, size and condition, a single-item US sale in USD, the actual sold price, date and source link. Exclude shipping, tax, bundles, cancellations and refunds. Do not substitute the asking price when an accepted-offer amount is unknown.

Medians reflect your saved, qualifying samples, not the entire market. No samples means no estimate; fewer than five are marked insufficient. Verify release dates, launch MSRP and official product status with brand sources. Out of stock does not establish retirement.

05 · Backup and transfer

On iPhone, open the “My” tab (我的), then “Data & backup” (数据与备份). On the website, open its Data & backup entry.

  1. Open “Data & backup” (数据与备份) and export the full backup with photos. Save the JSON file to your own Files or backup location, then confirm it is actually there.
  2. On the target device, open Data & backup and select that JSON file.
  3. Check the preview counts, confirm the merge, and spot-check products and photos afterward.

Backups include local photos referenced by saved products. Official images remain links. Unsaved drafts, display preferences and recognition caches are not part of the catalog backup.

Import merges by internal record ID: existing records are kept, and new IDs are added. An older backup will not overwrite an existing record. Items with the same name but different IDs may coexist. The current JSON limit is 256 MB. If import fails, keep both the original file and local data.

There is no account or cloud sync. Export before changing browsers or devices or uninstalling the app. Transfers between versions depend on the backup formats those versions support.

06 · Missing data after closing

Closing and reopening normally should not deliberately delete successfully saved data, but unsaved edits or interrupted writes may be lost. Use normal browsing mode and return to the same website and browser.

Clearing website data, browser storage eviction, uninstalling or changing devices can make local data unavailable. Look for your saved JSON backup first. If an error appears, preserve your data and original backup before retrying. We have no cloud copy to recover for you.

System-backup recovery depends on your iOS settings and backup state. Do not rely on it instead of a manual backup you have confirmed is saved.

07 · Get support

Include the app or website version, device and operating system, browser, steps to reproduce, and exact error text. Redact private information from screenshots.

Open a GitHub issue

Issues are normally public and posting may require a GitHub account. Do not upload full backups, private photos or account credentials. Support is provided through this issue tracker, not a private email address or phone number.
